# awesome-design-md (reference library)

84 DESIGN.md files in `design-md/<brand>/DESIGN.md`, each describing one product's visual language: colour, type, spacing, components, motion and tone. Source: https://github.com/VoltAgent/awesome-design-md (MIT, see `LICENSE`). `README.md` has the full index.

## How to use it in EvntCult

1. **EvntCult's own `DESIGN.md` (project root) is the source of truth.** Read it first. This library is for ideas, never for replacing it.
2. Pick one or two references for the specific question in hand, e.g. "how does Linear handle dense lists", "how does Stripe pace a landing page", and read only those files:
   `ls .claude/skills/awesome-design-md/design-md/` then open `design-md/<brand>/DESIGN.md`.
3. Borrow principles (proportions, hierarchy, rhythm, behaviour), then express them in EvntCult's own tokens, fonts and colours.
4. Never copy a brand's identity: no logos, wordmarks, signature colours used as a brand cue, product names or distinctive illustrations. EvntCult must never look like, or be mistaken for, another company's product.
